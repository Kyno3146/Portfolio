Site d'enchères

Description

Ce projet est notre seul projet du second semestre de deuxième année. Il consiste à améliorer la qualité du site d'enchères créé précédemment au premier semestre. Nous allons donc améliorer les performances du site en corrigeant des bugs, en documentant notre code, en améliorant la qualité du code et améliorant l'utilisation des logiciels externes. Dans ce projet, mes camarades et moi avons utilisé le langage de programmation JavaScript, PHP, CSS et HTML, ainsi que les logiciels externes suivants : GitHub pour la gestion de version, Trello pour la gestion de projet, et Visual Studio Code comme environnement de développement intégré (IDE). Pour ce projet, nous avons également eu recours a des API afin de récupéréer des informations telles que la liste des stars. Nous avons également mis en place des plug-ins externes tels que Mailisearch pour la recherche intelligente ou mailjet pour l'envoi de mail automatisé aux utilisateurs.
